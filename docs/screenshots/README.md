# Screenshots

Drop your app screenshots in this folder and embed them in the main
[`README.md`](../../README.md) Screenshots section.

**Suggested shots** (use these file names so the template in the README works
without edits):

| File name | What to capture |
|---|---|
| `mission-control.png` | The Mission Control dashboard (net worth, charts). |
| `live-markets.png` | Live Markets — movers, forex, market pulse. |
| `ai-desk.png` | The AI Desk with a few favorites analyzed. |
| `asset-detail.png` | An Asset Detail page (chart + technicals). |
| `about-me.png` | The About Me profile page. |
| `lock-screen.png` | The profile lock / password screen. |

**Tips**
- Capture at a consistent width (e.g. 1440px) for a clean grid.
- Use PNG for crisp UI text.
- Don't include real account numbers, balances you want private, or passwords —
  blur or use a demo profile if needed.

Then open `README.md` and uncomment the image table in the **Screenshots**
section.
